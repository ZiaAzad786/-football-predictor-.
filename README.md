# Football Predictor - Streamlit

## اجرا
```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## استقرار در Streamlit Cloud
- Repository: `YOUR_GITHUB_USERNAME/YOUR_REPOSITORY`
- Branch: `main`
- Main file path: `streamlit_app.py`

این نسخه فقط نام دو تیم را می‌گیرد و برای اجرا به Team ID نیاز ندارد.
